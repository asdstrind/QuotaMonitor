# Harness icons

Downloaded 2026-10-11 from official sources; embedded locally as original SVG path geometry.

- Codex / OpenAI Blossom: https://raw.githubusercontent.com/openai/openai-agents-python/main/docs/assets/logo.svg (official OpenAI repository). Original white mark retained.
- Claude: https://claude.ai/favicon.svg (official Claude site). Original #D97757 starburst retained.
- DSH / DeepSeek: https://raw.githubusercontent.com/deepseek-ai/DeepSeek-LLM/main/images/logo.svg (official DeepSeek repository). Original #4D6BFE whale path retained; the wordmark is excluded from the compact icon slot.
- Antigravity: Google Antigravity [official Press Assets](https://antigravity.google/press), Icon - White: https://antigravity.google/assets/image/brand/antigravity-icon__white.svg (downloaded 2026-10-17 for v1.6.1). Original SVG and white path retained byte-for-byte; proportional fit uses its artwork bounds in 14/16/20 DIP slots. The same embedded geometry serves Collapsed, Expanded, Alert Minimal and Settings. QuotaMonitor's own application icon is unchanged.

Geometry proportions are retained. Alert numbers use the existing QuotaMonitor platform palette (#19A67A / #E2672F / #4A8AF0). Fonts match Collapsed: Bahnschrift, SemiBold, 16 DIP.

v1.6.2 reuses these same four files and artwork bounds in Collapsed, Expanded,
Settings display selections, provider tabs and provider headings. No additional
logo files were downloaded. ClaudeCN remains the third-party data source;
the Claude mark identifies its model service and does not imply Anthropic affiliation.

# QuotaMonitor v1.6.6

Windows x64 本地构建。解压完整 `QuotaMonitor-v1.6.6-win-x64.zip` 后运行 `QuotaMonitor.exe`，自带 .NET 运行时，请保留整个目录。运行前从托盘退出旧版；v1.6.5 文件夹和 ZIP 可保留。

- 日期 Tooltip 根据实际 Morph 内容裁剪轮廓、卡片测量尺寸与日期方格定位，优先上方，空间不足时切换方向。卡片保持现有样式，不参与鼠标命中；Hover 不触发 Morph 内容重新布局。
- 热力图仍显示近 26 周。底部 Token 改为当前来源已保存、可核实的历史累计，未知值保持 `—`；不代表官方账户终身总量。
- 四个平台使用相同的累计定义。ClaudeCN 保留已取得的较早每日缓存，继续按原有有界批次回溯；不会凭空补全未取得的历史。
- Codex 新旧记录镜像按会话和计数字段逐条关联，避免格式切换漏计、压缩副本重复及不同会话计数碰撞；缓存输入与推理输出不重复相加。无效记录保留不完整标记。

保留四种形态、Morph 运动参数、字体、Harness 图标、配色、圆角热力图、OKLCH 算法、Settings 及平台筛选。DSH Bridge 仍为 v1.3.0，保留 v1.6.5 的 0.2.1-rc.5 兼容修复。
